# CuentasClaras

Aplicación web para visualizar y consultar reportes Excel de cuentas por pagar.

## Estructura

- frontend/  React + TypeScript + Vite + Tailwind
- backend/   Java + Spring Boot
- docs/      Documentación
- .github/   CI

## Ejecución

Backend:
    cd backend
    mvn spring-boot:run

Frontend:
    cd frontend
    npm install
    npm run dev
